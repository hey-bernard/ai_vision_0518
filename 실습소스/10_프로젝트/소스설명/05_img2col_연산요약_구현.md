# 05. img2col 연산 요약 및 구현 — 소스 설명

대응 노트북: `notebooks/05_img2col_연산요약_구현.ipynb`

## 한눈에 보기

합성곱은 원래 “창을 밀며 곱하고 더하기”를 반복합니다.  
`img2col`(또는 im2col)은 그 창들을 **한 번에 행렬로 펼쳐**, 빠른 **행렬곱(GEMM)** 으로 바꾸는 기술입니다.

비유: 흩어진 퍼즐 조각을 책상 위에 가지런히 늘어놓고, 한 번에 계산하는 것.

## 초보자를 위한 용어 사전

| 용어 | 쉬운 설명 |
|------|-----------|
| **img2col / im2col** | 이미지의 슬라이딩 창을 열(또는 행)로 펼쳐 큰 행렬을 만드는 변환. |
| **GEMM** | 일반 행렬곱(General Matrix Multiply). CPU/GPU 최적화가 매우 잘 되어 있음. |
| **naive convolution** | 이중 루프로 창마다 직접 곱합하는 느린(이해하기 쉬운) 구현. |
| **stride** | 창을 몇 칸씩 이동할지. 2면 한 칸씩 건너뜀. |
| **padding (pad)** | 테두리에 0을 붙여 출력 크기를 조절하는 것. |
| **채널 C** | 색 층. RGB면 C=3. 중간층은 64, 128 등 많을 수 있음. |
| **필터 개수 F** | 커널이 몇 개인지. 출력 Feature Map 개수. |
| **메모리 팽창** | img2col이 원본보다 훨씬 큰 행렬을 만들어 RAM을 많이 쓰는 현상. |

## 수식 직관

입력 `(C,H,W)`, 커널 `(F,C,KH,KW)`일 때:

```text
OH = (H + 2P - KH) // S + 1
OW = (W + 2P - KW) // S + 1

X_col 크기: (C*KH*KW, OH*OW)
W_col 크기: (F, C*KH*KW)
Y_col = W_col @ X_col  → reshape → (F, OH, OW)
```

## 주요 함수

| 함수 | 역할 |
|------|------|
| `conv2d_naive` | 느린 정답 구현 (검증용) |
| `img2col_2d` | 단일 채널 펼치기 |
| `img2col_chw` | 다채널 `(C,H,W)` 펼치기 |
| `conv2d_multi_naive` | 다채널·다중 필터 naive |
| `estimate_sizes` | 입력 대비 img2col 메모리 배수 추정 |

노트북은 `np.allclose`로 **naive 결과 = img2col+행렬곱 결과**임을 확인합니다.

## 장단점

- 장점: BLAS/GPU 최적화 행렬곱 활용 → 속도↑
- 단점: 중간 행렬이 커서 메모리↑
