# 11. 핵심 모듈 구축 (시각·센서·웹) — 소스 설명

대응 노트북: `notebooks/11_핵심모듈_시각분석_웹통합_센서연동.ipynb`

## 한눈에 보기

지금까지의 로직을 **재사용 가능한 모듈**로 나눕니다.

```text
[이미지] → VisionModule ─┐
                         ├→ FusionService → 웹/API 응답
[센서]   → SensorModule ─┘
```

산출물: `outputs/core_modules/` (예: `fusion_result.json`)

## 초보자를 위한 용어 사전

| 용어 | 쉬운 설명 |
|------|-----------|
| **모듈화** | 기능을 독립된 부품(클래스/함수)으로 나눠 조립하기 쉽게 만드는 것. |
| **API** | 다른 프로그램이 기능을 호출할 때 지키는 입출력 약속. |
| **FastAPI** | 파이썬으로 웹 API를 빠르게 만드는 프레임워크. |
| **Fusion** | 여러 점수를 가중 평균 등으로 합쳐 최종 판단을 만드는 것. |
| **risk score** | 위험/불량 가능성 점수 (보통 0~1). |
| **rule-based** | 학습 대신 ‘규칙’으로 점수를 매기는 방식. PoC에 흔함. |

## 클래스 역할

### `VisionModule`

- `extract_features`: 밝기/엣지 등
- `predict_risk`: rule-based vision_risk_score
- `run`: feature + score 반환

### `SensorModule`

- `clean`: 결측 보간 + IQR clip
- `feature_engineering`: rolling, z-score 등
- `predict_risk`: 최신 시점 z-score 기반 sensor_risk_score

### `FusionService`

```text
fused = w_vision * vision + w_sensor * sensor
risk_level = HIGH / MEDIUM / LOW (임계값 기준)
```

기본 가중치 예: vision 0.6, sensor 0.4
