# 10. 실제 모델 추론결과 자동 평가 리포트 — 소스 설명

대응 노트북: `notebooks/10_실제모델추론결과_자동평가리포트.ipynb`

## 한눈에 보기

학습된 모델의 추론 결과 파일(CSV/JSON)을 읽어  
**mAP 계산 + 클래스별 분석 + 오류 샘플 정리**까지 자동으로 만듭니다.

파일이 없으면 GT 기반 **데모 예측**을 만들어 학습용으로 돌립니다.

산출물: `outputs/auto_eval_report/`

## 초보자를 위한 용어 사전

| 용어 | 쉬운 설명 |
|------|-----------|
| **추론 (inference)** | 학습이 끝난 모델에 새 이미지를 넣어 예측을 뽑는 단계. |
| **자동 평가 리포트** | 사람이 매번 계산하지 않고 스크립트가 지표·표를 저장하는 것. |
| **스키마** | 파일이 가져야 할 컬럼/필드 규칙. |

## 입력 포맷

**CSV 필수 컬럼**

`image_id, class_id, conf, x1, y1, x2, y2`

**JSON 예시**

```json
[{"image_id": "...", "class_id": 2, "conf": 0.87, "bbox": [0.11, 0.22, 0.19, 0.30]}]
```

설정 변수:

```python
PRED_PATH = PROJECT_ROOT / "predictions" / "detections.csv"
EVAL_SPLIT = "test"
MAX_IMAGES = 400
```

## 코드가 하는 일

1. GT 로드 (`load_gt`)
2. 예측 로드 (`load_predictions`) — CSV/JSON 자동 분기
3. 없으면 `make_demo_predictions_from_gt`
4. IoU 스윕으로 mAP@0.5, mAP@0.5:0.95 계산
5. 리포트 CSV/요약 저장, 오류 유형 분석

## 실무에서 쓰는 법

1. YOLO 등으로 추론 → CSV/JSON export
2. `PRED_PATH`만 실제 경로로 변경
3. 노트북 실행 → `outputs/auto_eval_report/` 확인
