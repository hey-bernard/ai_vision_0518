## 초보자를 위한 용어 사전

| 용어 | 쉬운 설명 |
|------|-----------|
| **품질 게이트** | 데이터가 기준 미달이면 파이프라인을 막는 검문소. |
| **스키마 검증** | 필수 컬럼·값 범위가 맞는지 검사. |
| **증분 처리** | 이미 처리한 ID는 건너뛰어 시간 절약. |
| **파이프라인 버전** | 단계 구성을 버전/해시로 남겨 재현 가능하게 함. |
| **DAG** | 단계를 방향 있는 그래프로 연결한 실행 순서. |
| **처리량 (throughput)** | 초당/분당 몇 건 처리하는지. |
| **p95 Latency** | 느린 쪽 5%를 제외한 대표 지연. 체감 성능에 가깝. |
| **배치 추론** | 여러 장을 묶어 한 번에 추론해 GPU/CPU 효율↑. |
| **캐시** | 같은 입력 재계산을 피하려고 결과를 저장. |

## 코드 하이라이트

### `validate_sensor_schema` / `quality_gate_sensor`

결측률·이상치 비율이 임계값을 넘으면 `passed=False`.

### `PipelineState`

`processed_ids`를 JSON에 저장해 증분 처리.

### `IndustrialPipeline`

스테이지를 `add`로 등록하고 `fingerprint()`로 버전 해시 생성 후 `run`.

### 배포 벤치

단건 vs 배치, 캐시 hit/miss, 해상도 축소 등 전략별 ms 비교.

## 고도화 맵

```text
원천 데이터 → 품질 게이트 → 전처리 파이프라인 vN
→ 배치/캐시 추론 → Fusion/LLM → 모니터링 메트릭
```
