## 초보자를 위한 용어 사전

| 용어 | 쉬운 설명 |
|------|-----------|
| **PCB** | 전자제품에 들어가는 초록색(또는 다른 색) 회로 기판. Printed Circuit Board. |
| **AOI** | 카메라로 기판을 찍어 불량을 자동으로 찾는 검사 장비. Automated Optical Inspection. |
| **Vision AI** | 이미지/영상을 보고 판단하는 인공지능. |
| **객체 검출 (Object Detection)** | 사진 안에서 ‘어디에 무엇이 있는지’ 네모 상자(바운딩 박스)와 종류를 함께 찾는 과제. |
| **바운딩 박스 (bbox)** | 결함 위치를 감싸는 직사각형. ‘여기가 문제 구간’이라고 표시하는 상자. |
| **YOLO** | 객체 검출 모델/라벨 형식의 대표 이름. 라벨은 보통 `클래스 cx cy w h` 한 줄. |
| **지도학습** | 정답(라벨)이 있는 데이터로 ‘이렇게 맞혀라’고 배우는 방식. |
| **KPI** | 성공을 숫자로 재는 핵심 지표. Key Performance Indicator. |
| **ROI** | 투자 대비 얼마나 이득인지. Return On Investment. |
| **Recall (재현율)** | 실제 불량 중 AI가 놓치지 않고 잡은 비율. 높을수록 미검이 적음. |
| **Precision (정밀도)** | AI가 ‘불량’이라고 한 것 중 진짜 불량인 비율. 높을수록 오검이 적음. |
| **FPR** | 양품을 불량으로 잘못 판정하는 비율. False Positive Rate. |
| **mAP** | 객체 검출에서 여러 클래스 성능을 평균 낸 대표 점수. |
| **엣지 GPU** | 공장 라인 옆에 두고 실시간으로 돌리는 GPU 컴퓨터. |
| **Latency** | 한 장을 검사하는 데 걸리는 시간(지연시간). |

## 코드가 하는 일

### 셀: `dataset.yaml` 읽기

```python
PROJECT_ROOT = Path("..").resolve()
CONFIG_PATH = PROJECT_ROOT / "config" / "dataset.yaml"
dataset_cfg = yaml.safe_load(f)
```

- `Path("..")`: 노트북이 `notebooks/`에 있으므로 한 단계 위(프로젝트 루트)로 이동
- `yaml.safe_load`: 설정 파일을 파이썬 딕셔너리로 읽기
- 출력: 결함 클래스 개수(`nc`)와 이름(`names`) 확인

### 셀: ML 문제 정의서 (`ml_problem_definition`)

딕셔너리로 “무엇을 입출력할지”를 문서로 고정합니다.

| 키 | 의미 |
|----|------|
| `task_type` | 과제 종류 → 여기서는 `object_detection` |
| `output_format` | YOLO 박스 형식 |
| `latency_requirement_ms` | 한 장당 목표 시간(예: 50ms) |
| `success_metrics` | 성공 기준(mAP, Recall 등) |

### 셀: ROI 계산

```text
연간 절감액 ≈ (육안 유출 건수 - AI 유출 건수) × 유출 1건 비용
```

변수를 바꿔가며 “AI를 넣으면 돈이 얼마나 아끼는지” 감을 잡습니다.

## 왜 객체 검출을 골랐나?

| 방법 | 결과 | 부족한 점 |
|------|------|-----------|
| 이진 분류 | OK/NG만 | 어디가 문제인지 모름 |
| 다중 분류 | 종류만 | 위치 없음 |
| **객체 검출** | 위치+종류 | 라벨링 비용은 있음 |
| 세그멘테이션 | 픽셀 단위 윤곽 | 라벨 비용이 매우 큼 |
