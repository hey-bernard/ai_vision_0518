## 초보자를 위한 용어 사전

| 용어 | 쉬운 설명 |
|------|-----------|
| **PoC** | 가능성 검증용 프로토타입. Proof of Concept. |
| **Production** | 실제 공장/서비스에 올려 매일 쓰는 시스템. |
| **갭 분석** | 현재와 목표의 차이를 축별로 점수화해 우선순위를 정하는 것. |
| **성숙도** | 데이터·모델·시스템·운영·비즈니스가 얼마나 준비됐는지 1~5점 등. |
| **fp16 / fp32** | 숫자를 16비트/32비트로 저장. fp16은 대체로 더 가볍고 빠름. |
| **Warmup** | 첫 추론 전 한 번 예열해 초기 지연을 줄이는 것. |
| **엣지 배포** | 클라우드가 아니라 라인 옆 장비에서 추론을 돌리는 것. |
| **도메인 적응** | 새 제품/조명 등 현장 변화에 맞게 데이터를 추가·재학습. |

## PoC vs Production (노트북 표 요약)

| 축 | PoC | Production 목표 |
|----|-----|-----------------|
| 데이터 | 정적 셋 + 시뮬 센서 | 실시간 MES/센서 |
| 모델 | Rule/Mock | 학습 검출 모델 + 검증 LLM |
| 지연 | 노트북 | Edge p95 목표 강화 |
| 신뢰성 | 수동 테스트 | SLA·자동 알람 |
| 확장 | 단일 라인 | 다라인·다제품 |

## 한계 5축

1. 데이터 — 라벨 불일치, 시뮬 센서, 조명 편향
2. 모델 — rule score, Mock LLM, 시뮬 mAP
3. 시스템 — 인프로세스, 단건 추론
4. 운영 — 모니터링 시뮬, 피드백 초기 단계
5. 비즈니스 — ROI 가정치

## 배포 최적화 실습 전략

| 전략 | 효과 |
|------|------|
| Precision(fp16) | 메모리·대역폭↓ |
| Batch | 처리량↑ |
| Cache | 재검사 시간↓ |
| Resize | 속도↑ (품질 trade-off) |
| Warmup | 첫 요청 지연↓ |

노트북은 각 전략의 실행 시간을 비교해 **개선 효과**를 숫자로 보여 줍니다.
