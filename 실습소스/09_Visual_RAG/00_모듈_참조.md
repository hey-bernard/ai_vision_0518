# 노트북 연동 모듈 참조

`02_` · `03_` 노트북과 `conveyor_analyze` 스크립트·API가 공유하는 Python 모듈 목록입니다.

## 노트북에서 모듈 불러오기

```python
import sys
from pathlib import Path

ROOT = Path(".").resolve()
CONVEYOR_ANALYZE = ROOT / "conveyor_analyze"
sys.path.insert(0, str(CONVEYOR_ANALYZE))

from conveyor_rag.metadata_link import build_frame_sensor_table
from conveyor_rag.plot_utils import setup_korean_matplotlib
```

> **03 노트북**은 환경 설정 셀에서 위와 같이 `conveyor_analyze`를 `sys.path`에 등록한 뒤 모듈을 import 합니다.  
> **02 노트북**은 대부분 셀 안에 동일 로직을 직접 구현하며, 파이프라인·API는 아래 모듈과 동일 구조입니다.

---

## `conveyor_rag/` — 핵심 라이브러리

| 경로 | 주요 내용 |
|------|-----------|
| `conveyor_analyze/conveyor_rag/config.py` | 프로젝트·데이터 경로, 모델 ID, ChromaDB 컬렉션명, API 기본 URL 등 **전역 상수** |
| `conveyor_analyze/conveyor_rag/encoder.py` | **SigLIP2Encoder** — 이미지·텍스트 임베딩, GPU 해제(`unload`) |
| `conveyor_analyze/conveyor_rag/sensor.py` | **sensor.csv** 생성·조회, 프레임명 정규화, 시드 센서 데이터 |
| `conveyor_analyze/conveyor_rag/store.py` | **ChromaStore** — 프레임 임베딩 + 센서 메타를 `conveyor_siglip2` 컬렉션에 저장·검색 |
| `conveyor_analyze/conveyor_rag/metadata_link.py` | **이미지·센서·Chroma 메타 연계** — 조인 테이블, 동기화 검증, 검색 결과 enrichment |
| `conveyor_analyze/conveyor_rag/analysis_store.py` | **AnalysisVectorStore** — Qwen 분석 텍스트를 `conveyor_analysis_results` 컬렉션에 저장·검색 |
| `conveyor_analyze/conveyor_rag/analyzer.py` | **QwenAnalyzer** — 1장씩 VL 분석 후 종합, **HistoryStore** — JSON 분석 이력 |
| `conveyor_analyze/conveyor_rag/pipeline.py` | ZIP/영상 → 프레임 → sensor.csv → SigLIP2 → ChromaDB **일괄 파이프라인** |
| `conveyor_analyze/conveyor_rag/plot_utils.py` | **setup_korean_matplotlib()** — matplotlib 한글 폰트 설정 (Windows·Colab·macOS) |
| `conveyor_analyze/conveyor_rag/__init__.py` | 패키지 개요 docstring |

### 모듈별 대표 함수·클래스

| 모듈 | 심볼 | 기능 |
|------|------|------|
| `config` | `DATA_DIR`, `CHROMA_DIR`, `QWEN_MODEL_ID` | 데이터·모델 경로 상수 |
| `encoder` | `SigLIP2Encoder.encode_images/texts` | 벡터 임베딩 |
| `sensor` | `generate_sensor_csv`, `get_sensor_by_frame` | 가상 센서 CSV |
| `store` | `ChromaStore.build_from_frames`, `.search` | 이미지 벡터 DB |
| `metadata_link` | `build_frame_sensor_table`, `verify_chroma_sensor_sync`, `enrich_hits_with_sensor` | 메타 연계 실습 |
| `analysis_store` | `AnalysisVectorStore.add_result`, `.search` | 분석 결과 벡터 DB |
| `analyzer` | `QwenAnalyzer.analyze_with_sensor`, `HistoryStore.add` | VL 분석·JSON 이력 |
| `pipeline` | `run_full_pipeline` | 전체 배치 실행 |
| `plot_utils` | `setup_korean_matplotlib` | 차트 한글 표시 |

## `api/` — FastAPI REST 서비스

| 경로 | 주요 내용 |
|------|-----------|
| `conveyor_analyze/bootstrap.py` | `conveyor_analyze` 루트를 `sys.path`에 등록 (API import 전제) |
| `conveyor_analyze/api/schemas.py` | Pydantic 요청 스키마 (`SearchRequest`, `AnalyzeRequest` 등) |
| `conveyor_analyze/api/main.py` | REST 엔드포인트 — `/search`, `/analyze`, `/sensor`, `/metadata/*`, `/analysis/search` |

### 주요 API 엔드포인트

| Method | Path | 설명 |
|--------|------|------|
| GET | `/` | 서비스 상태·벡터 건수 |
| POST | `/search` | 텍스트 → SigLIP2 → 프레임 Top-k (+ 센서) |
| POST | `/analyze` | Visual RAG — 검색 + Qwen3-VL + 이력·분석 벡터 저장 |
| GET | `/sensor` | sensor.csv 조회 |
| GET | `/metadata/frames` | 프레임 ↔ 센서 조인 테이블 |
| GET | `/metadata/verify` | Chroma 메타 ↔ CSV 동기화 검증 |
| POST | `/analysis/search` | 과거 분석 결과 벡터 검색 |
