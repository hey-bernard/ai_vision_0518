# 에어피팅 유형 가이드 — KRPPL형 vs KRPUC형

[AI Hub 에어 피팅 조립 상태 데이터](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71927) 샘플(`Air_Fitting_Type_Detection.zip`) 기준 정리입니다.

관련 노트북:

- `14_Air_Fitting_EDA.ipynb` — 데이터 탐색
- `15_YOLO11_Air_Fitting_Detection.ipynb` — YOLO11 종류 검출

---

## 1. 개요

**KRPPL형**과 **KRPUC형**은 중간 조립모듈 이미지에서 에어피팅 부품의 **종류(유형)** 를 구분하는 라벨 필드 `Annotation_part_type` 값입니다.

AI Hub 권장 모델인 **YOLOv11**은 이 유형을 B-box로 검출하는 데 사용됩니다. 샘플 데이터셋에는 위 **2종**만 포함되어 있습니다.

---

## 2. 한눈에 비교

| 구분 | KRPUC형 | KRPPL형 |
|------|---------|---------|
| 이름 해석 | **C** = Straight (직선형) | **L** = Elbow (엘보, ㄱ자형) |
| 역할 | 튜브를 **직진**으로 연결 | 배관 방향을 **90° 꺾어** 연결 |
| 제품 코드 예 | `KRPUC-06-16`, `KRPUC-08-16` | `KRPPL-12-22` |
| 튜브 호수 (샘플) | 6 mm, 8 mm | 12 mm |
| B-box 평균 크기 (샘플) | 약 112 × 174 px (세로로 김) | 약 140 × 139 px (거의 정사각) |
| B-box 가로/세로 비 | 약 0.64 | 약 1.03 |
| 샘플 어노테이션 수 | 290개 | 429개 |

---

## 3. 제품 코드 명명 규칙

JSON `Part_info` 필드 예시:

```text
KRPUC-06-16 1ea, KRPPL-12-22 3ea, KRPUC-08-16 1ea
```

코드 구조 해석:

| 구성 | 의미 |
|------|------|
| `KRPU` | 해당 조립모듈(㈜엠스코 등)에서 사용하는 **원터치 피팅 제품군** |
| `C` / `L` | **직선(Straight)** / **엘보(Elbow)** 형상 구분 |
| `06-16`, `08-16`, `12-22` | 튜브 호수·나사 규격 등 사양 (예: 6 mm 튜브, 1/6 나사) |

공압 피팅 업계에서 SMC 등이 `PC`(직선), `PL`(엘보)로 형상을 나누는 방식과 유사하게, **C = 일자 연결**, **L = 90° 꺾임 연결**로 이해할 수 있습니다.

---

## 4. 기능적 차이

### KRPUC형 (직선형)

- 공압 튜브를 **같은 방향으로** 이어 붙이는 용도
- 모듈 내부 **일자 연결** 구간에 주로 사용
- 카메라 기준 **세로로 긴** 실루엣으로 관찰되기 쉬움

```text
[튜브] ──→ [KRPUC 피팅] ──→ [튜브/나사]
```

### KRPPL형 (엘보형)

- 좁은 공간에서 배관 **방향을 90° 전환**하는 용도
- ㄱ자 형태이므로 **가로로 넓은** B-box가 많음
- 샘플 조립모듈에서는 수량이 더 많음 (예: KRPPL 3ea, KRPUC 1~2ea)

```text
[튜브]
   │
   └──→ [KRPPL 피팅] ──→ [다른 방향 튜브]
```

## 5. 데이터셋에서의 관찰 (샘플 200장)

### 5.1 라벨 JSON 예시

파일: `02.라벨링데이터/중간조립모듈/Module_001_A_CV_00_0001.json`

| 항목 | KRPUC형 | KRPPL형 |
|------|---------|---------|
| B-box | [913, 395, 988, 531] | [721, 495, 866, 603] |
| 체결 상태 | 완전체결 상태 | 완전체결 상태 |
| 모듈 Part_info | KRPUC-06-16 1ea, KRPUC-08-16 1ea | KRPPL-12-22 3ea |

### 5.2 통계 요약

- **한 이미지에 두 유형이 함께** 등장하는 경우가 많음
- 이미지당 어노테이션: 평균 약 3.6개 (최소 2, 최대 5)
- 샘플 전체 검출 클래스: `KRPUC형` 290건, `KRPPL형` 429건
- 샘플 조립모듈의 `Part_info`에 등장하는 코드: `KRPUC-06-16`, `KRPUC-08-16`, `KRPPL-12-22`

### 5.3 B-box 크기 (픽셀, 1920×1200 기준)

| 유형 | 평균 너비 | 평균 높이 | 상대 면적 (평균) |
|------|-----------|-----------|------------------|
| KRPUC형 | 111.5 | 174.0 | 0.0085 |
| KRPPL형 | 139.5 | 138.7 | 0.0084 |

KRPUC형은 **세로로 길고**, KRPPL형은 **가로·세로가 비슷**하여 YOLO가 형상으로 구분하기에 유리합니다.

## 6. 단품 데이터 분류와의 관계

| 데이터 종류 | 분류 필드 | 예시 |
|-------------|-----------|------|
| 단품 에어피팅 | `Product_classification` | 원터치 피팅, 컴팩트 원터치 피팅, SUS 피팅, Brass 피팅 … |
| 중간 조립모듈 | `Annotation_part_type` | **KRPUC형**, **KRPPL형** … |

- **단품 데이터**: 제조사 카탈로그 기준 **제품 카테고리** (B-box 없음, 메타데이터만 제공)
- **조립모듈 데이터**: 모듈에 실제 체결된 **구체 부품 모델군** (B-box + 유형 라벨)

두 분류 체계는 목적과 granularity가 다릅니다.

## 7. AI Hub 전체 데이터와의 관계

| 항목 | 샘플 zip | 전체 데이터 (AI Hub) |
|------|----------|----------------------|
| 조립모듈 이미지 | 200장 | 217,765장 |

## 8. 체결 상태와의 구분

`Annotation_part_type`(종류 검출)과 별도로, 같은 B-box에는 체결 상태 정보도 포함됩니다.

| 필드 | 값 예시 | 담당 모델 (AI Hub 권장) |
|------|---------|-------------------------|
| `Annotation_part_type` | KRPUC형, KRPPL형 | **YOLOv11** (종류 검출) |
| `Subclass_status` | 완전체결, 부분체결, 미체결, 오류체결 | **Swin Transformer** (상태 분류) |

샘플 데이터에는 `Subclass_status`가 **완전체결 상태**만 포함되어 있습니다.
